# حلقه‌یار — Android

این پروژه یک پوستهٔ اندرویدی Kotlin دارد و رابط فعلی سایت را داخل WebView امن نمایش می‌دهد. فایل‌های HTML/CSS/JS، تصاویر و فونت‌ها هنگام ساخت از ریشهٔ مخزن به assets اپلیکیشن کپی می‌شوند. در نتیجه رابط داخل APK از نسخهٔ وب مستقل است، ولی هر دو به همان Google Apps Script متصل می‌مانند.

## مشخصات اولیه

- Application ID: ir.halgheyar.app — پس از انتشار اولین نسخه نباید تغییر کند.
- حداقل Android: 6.0 (API 23)
- Java: 17
- WebView محلی با WebViewAssetLoader و آدرس HTTPS محلی
- بدون addJavascriptInterface و بدون اجازهٔ محتوای HTTP ناامن
- پشتیبانی از دکمهٔ بازگشت، خطای بارگذاری و تلاش مجدد

## ساخت در Android Studio

1. Android Studio به‌روز را باز کن.
2. پوشهٔ android را باز کن.
3. JDK 17 را برای Gradle انتخاب کن.
4. صبر کن Gradle Sync و دانلود وابستگی‌ها کامل شود.
5. از منوی Build، گزینهٔ Build APK(s) را اجرا کن.

## امضای انتشار

کلید امضای انتشار هنوز ساخته نشده است. پیش از اولین انتشار عمومی، یک keystore اختصاصی بساز و دو نسخهٔ رمزگذاری‌شدهٔ پشتیبان را در محل‌های امن جداگانه نگه دار. فایل keystore، رمز آن و کلیدهای خصوصی را هرگز به GitHub یا این مخزن اضافه نکن.

Application ID و گواهی امضا باید برای تمام نسخه‌های بعدی ثابت بمانند. برای نسخه‌های بعدی، versionCode را افزایش بده.

## همگام‌سازی رابط

برای تغییر رابط وب، فایل‌های ریشهٔ مخزن را ویرایش کن. برای تغییرات مخصوص اندروید، فایل‌های داخل android/app/src/main را ویرایش کن. رابط وب در زمان ساخت APK بسته‌بندی می‌شود.
